# Progressive onboarding workflow

The minimum resumable path has three steps:

1. career starting point: existing CV, recent role, or education/project;
2. target countries and structured work-authorisation requirement;
3. direction: Role Pathways or analysis of a real vacancy.

Completion opens the selected result rather than an empty dashboard. Progress
is schema-validated and stored under
`autotime-progressive-onboarding:v1:<authenticated-user-id>`. Invalid or
cross-user values are rejected and reset safely.

Recommended information is collected later in context: coding preference in
pathways, salary during job analysis, form-specific fields before autofill,
verified achievements before application material, and language information
when country or vacancy context requires it.
