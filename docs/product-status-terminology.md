# Product status and terminology dictionary

| Domain        | Allowed labels                                                                               |
| ------------- | -------------------------------------------------------------------------------------------- |
| Job viability | Apply, Consider, Skip, Insufficient information                                              |
| Evidence      | Confirmed, Inferred, Missing, Conflicting                                                    |
| Market        | Strong observed signal, Moderate observed signal, Limited observed signal, Insufficient data |
| Mobility      | Viable, Potentially viable, Constrained, Insufficient information, Not assessed              |
| Application   | Saved, Analysed, Preparing, Ready, Applied, Interview, Offer, Rejected, Withdrawn            |
| Readiness     | Ready, Ready with limitations, Information needed                                            |
| Profile guide | Getting started, Enough to explore, Good evidence coverage, Strong evidence coverage         |

## Presentation rules

- Always pair colour with text.
- Prefer a qualitative label; exact scores belong in “View evidence”.
- “Sponsorship observed” is not “sponsorship confirmed”.
- Employer register presence never proves vacancy sponsorship.
- Never use probability, guarantee, ATS success or visa eligibility language.
- Existing stored legacy statuses may be mapped for display but must not be
  silently rewritten without a migration plan.
- Never describe an overall profile percentage as access, accuracy or outcome
  assurance.
