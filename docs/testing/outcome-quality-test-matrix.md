## Automation Notes

- Vitest is not currently configured in the repo. Existing tests are Node-based
  `.mjs` scripts. These outcome tests can first be added as Node tests, then
  migrated to Vitest if the project adopts it.
- Playwright is not currently configured in the repo. Full browser outcome tests
  are marked as Playwright candidates, not implemented.
- Manual tests should use fake job/profile data only and should not enter real
  CV text, job descriptions, email, phone, visa/share-code, payment data,
  cookies, tokens, or API keys.
