# Private Beta Feedback Questions

Last updated: 2026-05-23

Use these questions after a founder-led walkthrough. Do not collect sensitive
personal data, real CV text, full job descriptions, visa/share-code data,
payment data, cookies, tokens, API keys, or secrets.

## Product Clarity

1. Was the product clear within the first few minutes?
2. Did you understand that this is a Private Beta / Early Access product?
3. Did each step have a clear next action?
4. What confused you most?

## Job Import

5. Did job import work or did you know what to paste/import?
6. Was the required job evidence clear?
7. What would make the job import step easier?

## EU Fit

8. Did the EU fit recommendation make sense?
9. Did you trust the reasoning?
10. Did the product explain uncertainty, sponsorship, visa, or work-right risks clearly?
11. What would make the fit result more useful?

## Application Kit

12. Was the application kit useful?
13. Was it strong enough to copy, edit, and use?
14. Did it feel role-specific?
15. Did it avoid fake or unsupported claims?
16. What should be improved before public launch?

## Trust And Value

17. Did the product feel commercially valuable?
18. Would you use this for real applications?
19. Would you recommend this to another jobseeker?
20. What would make you come back and use it again?

## Final Feedback

21. What was the strongest part of the product?
22. What was the weakest part?
23. What bug or confusing moment should be fixed first?
24. What outcome would make this product worth paying for later?
