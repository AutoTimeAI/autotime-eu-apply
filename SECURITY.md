# Security Policy

## Supported Versions

Security fixes are applied to the current `main` branch and the latest
production deployment.

## Reporting a Vulnerability

Please report suspected vulnerabilities to support@autotime.ai.

Include:

- A clear description of the issue.
- Steps to reproduce.
- Affected URL, extension version, or commit hash where possible.
- Any proof-of-concept details that help us verify safely.

We aim to acknowledge credible reports within 5 business days. Please do not
publicly disclose a vulnerability until we have had a reasonable opportunity to
investigate and release a fix.

## Scope

In scope:

- AutoTime web app authentication, sync, billing, dashboard, and analytics.
- AutoTime browser extension permissions, storage, and autofill behavior.
- Supabase data access rules and server-side API routes.

Out of scope:

- Third-party platforms such as job boards, ATS sites, OpenAI, Stripe, Vercel,
  Supabase, or PostHog.
- Social engineering, spam, denial-of-service, or physical attacks.
