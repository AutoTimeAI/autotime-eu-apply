# Privacy Summary

AutoTime is designed around clear user control and evidence-based assistance.

## Data Stored

AutoTime may store:

- Account identifiers used for sign-in.
- Candidate profile information you choose to save.
- CV evidence, reusable answers, job descriptions, applications, notes, and
  interview preparation records.
- Extension connection and sync status when cloud sync is enabled.

## Where Data Is Stored

- Browser extension data is stored locally in Chrome extension storage unless
  cloud sync is enabled.
- Web dashboard account and product data is stored in Supabase.
- The web application is hosted on Vercel.
- Python analytics uses submitted evidence and outcome records to produce
  descriptive analytics and ML-readiness signals.

## Third-Party Processors

AutoTime may use:

- Supabase for authentication and database storage.
- Vercel for hosting and serverless/services runtime.
- OpenAI only when AI features are used.
- Stripe for subscription payments.
- PostHog EU for consent-gated product analytics.

AutoTime does not sell personal data.

## AI And Analytics Limits

AI output must be based on user-provided profile, CV, reusable answers, job text,
and saved evidence. Analytics are descriptive unless enough real outcomes exist
for calibration. AutoTime does not provide immigration, legal, or employment
authorisation decisions.

## Deletion

Users can remove local extension data from extension settings and may request
account data deletion by contacting support@autotime.ai.
